# Splunk SIEM Hands-on Portfolio

## Project Overview

This repository showcases my hands-on learning and practical exercises in Splunk SIEM through TryHackMe labs. It documents my understanding of Splunk fundamentals, Search Processing Language (SPL), log analysis, and security monitoring.

## Learning Objectives

- Understand the fundamentals of Splunk SIEM.
- Explore Splunk architecture and its core components.
- Practice searching and analyzing machine-generated data.
- Learn and apply Search Processing Language (SPL).
- Investigate VPN and Windows log data.
- Understand security event analysis and anomaly detection.

## Tools & Technologies

- Splunk
- Splunk Search & Reporting
- Search Processing Language (SPL)
- TryHackMe
- Windows and VPN log datasets

## Practical Modules

### 1. Splunk: The Basics

Topics covered:
- Introduction to Splunk
- Splunk architecture
- Forwarders, Indexers, and Search Heads
- Adding and searching data
- Indexes and events

### 2. Splunk: Exploring SPL

Topics covered:
- SPL fundamentals
- Searching and filtering events
- Field extraction
- Statistical commands
- Data transformation and analysis
- Lookups and subsearches
